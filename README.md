# Mimo's Take Away

Redesign concept for Mimo's Take Away, a Portuguese takeaway restaurant in Vila Nova de Gaia.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui primitives
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deploying to Vercel

Import the GitHub repository into Vercel. Vercel detects Vite automatically and uses:

- Build command: `npm run build`
- Output directory: `dist`

No environment variables are required.

## Content and assets

Business information, menu links, prices and photography are sourced from the restaurant's existing website and Uber Eats storefront. The menu PDF remains hosted by the restaurant's current website provider.
